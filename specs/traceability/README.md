# Matrices y Auditoría de Trazabilidad (`specs/traceability/`)

Este directorio contiene las herramientas y matrices de trazabilidad que aseguran la correspondencia integral entre la normativa tributaria de SUNAT, el estándar OASIS UBL 2.1, el modelo de dominio y la implementación de ABC Software Corp.

---

## 1. Documentos Principales

- **[`sunat-ubl-traceability-matrix.md`](file:///d:/Projects/MedioCurso/MedioCurso/specs/traceability/sunat-ubl-traceability-matrix.md):** Matriz normativa principal que mapea 23 puntos de control fiscal entre la RS 097-2012/SUNAT, entidades de dominio, contratos DTO, elementos UBL 2.1 (`cac:`, `cbc:`), restricciones XSD y pruebas automatizadas.
- **[`specs/templates/traceability-matrix-template.md`](file:///d:/Projects/MedioCurso/MedioCurso/specs/templates/traceability-matrix-template.md):** Plantilla para matrices modulares adicionales.
