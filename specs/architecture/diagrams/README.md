# Diagramas de Arquitectura y Dominio (`specs/architecture/diagrams/`)

Este directorio almacena los modelos visuales y diagramas estructurales del sistema.

---

## 1. Tipos de Modelos Esperados

- **Diagramas de Contexto (C4 Nivel 1):** Delimitación de fronteras del sistema, usuarios y sistemas externos.
- **Diagramas de Contenedores y Componentes (C4 Niveles 2 y 3):** Distribución interna del monolito MVC limpio (`controllers`, `views`, `services`, `domain`, `infrastructure`).
- **Modelo Conceptual del Dominio:** Entidades del negocio, atributos esenciales y relaciones semánticas extraídas del caso de estudio.
- **Diagramas de Secuencia / Flujo:** Representación visual del flujo de datos entre capas para los casos de uso principales.

---

## 2. Formato Recomendado

Se prioriza el uso de especificaciones basadas en texto plano como **Mermaid** o **PlantUML** dentro de archivos Markdown para facilitar el control de versiones, revisión de cambios y mantenimiento continuo.
